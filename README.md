# Boeing Digital Twin Demo

This project is a lightweight interactive demo for the Boeing supply-chain decision model described in the attached requirement document. It visualizes the make-vs-buy decision, highlights risk and time-benefit tradeoffs, and shows the decision logic behind the supply-chain twin.

## Run locally

Open `index.html` directly in a browser, or serve the folder locally:

```bash
cd "c:\Users\teaga\Projects\Boeing-Digital-Twin-Demo"
python -m http.server 8000
```

Then open <http://localhost:8000>.
